## ⚡ Quick Start

### Prerequisites
- Node.js 18+
- npm or pnpm or yarn

### Installation
```bash
git clone https://github.com/Vishwakarmasuraj333/PulseSocial8.git
cd PulseSocial8
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### Run Test Suite
```bash
npm test
```

### Production Build
```bash
npm run build
```
